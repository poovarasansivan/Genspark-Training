# Topics

- Working with Ngrx state management with selector, actions, reducers, state.

| Ngrx Element | Description                                                            |
| ------------ | ---------------------------------------------------------------------- |
| Store        | Global state container (single source of truth).                       |
| Actions      | Plain objects describing what happened (e.g., ADD_USER, LOAD_USERS).   |
| Reducers     | Pure functions that take current state and action to return new state. |
| Selectors    | Functions to read slices of state from the store.                      |
